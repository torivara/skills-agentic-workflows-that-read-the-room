## Recent developer updates

- **Reuse agent instructions:** Package repeatable engineering tasks as versioned skills, while keeping tools, project context, and permissions specific to the host running the agent. [GitHub Blog, November 12](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/)
- **Review Copilot model choices:** GitHub deprecated several Copilot models on November 16. For GPT-5.6 Terra, the Changelog suggests GPT-6.1 Sol or GPT-6 Luna; verify availability and your organization's model policies before updating integrations. [GitHub Changelog, November 16](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026/)
